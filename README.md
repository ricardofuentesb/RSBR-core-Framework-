RSB-R Core Framework: Recurrencia Bariónica Sólida y el Efecto Ricardo

​1. Introducción

​El RSB-R Core Framework constituye el repositorio central para la gestión, simulación y desarrollo técnico del modelo de Recurrencia Bariónica Sólida (RSB-R) y el Efecto Ricardo. Este marco teórico propone una descripción determinista de la cosmogonía y la geodinámica, fundamentada en la recurrencia periódica de densidades bariónicas y su acoplamiento dinámico.

3. Estructura del Repositorio

​/scripts/: Módulos en Python para la simulación geodinámica (análisis de profundidad sísmica PROF) y procesamiento de catálogos astronómicos.
​/docs/: Documentación técnica, addéndums de investigación y reportes de validación.
​/data/: Matrices de datos normalizados y resultados de simulaciones.
​4. Compromiso con el Rigor

​Toda modificación a este repositorio debe respetar la nomenclatura estricta de las constantes del modelo. Cualquier variación en los parámetros debe ser justificada mediante el flujo de trabajo de control de versiones y documentada en los archivos de trazabilidad.
