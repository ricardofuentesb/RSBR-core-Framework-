# Directorio de Datos: RSB-R Core Framework

Este directorio contiene los catálogos y matrices normalizadas necesarias para las simulaciones geodinámicas y cosmológicas del modelo RSB-R.

## Catálogos Disponibles
- `/seismics`: Matrices de datos sísmicos (normalizados con la constante RSB-R). Incluye la variable PROF (profundidad).
- `/astronomical`: Catálogos astronómicos, incluyendo mediciones de referencia para Messier 77.

## Normas de Integridad
Todo archivo de datos debe estar normalizado para asegurar la consistencia en el acoplamiento del Efecto Ricardo. Las modificaciones en las matrices deben estar respaldadas por el registro de cambios en el repositorio.
